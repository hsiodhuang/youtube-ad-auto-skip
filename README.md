# 网页版 YouTube 广告自动跳过_Google Chrome 插件

**离开键盘，也能少一点广告打断。**

一个轻量的 Chrome 扩展：广告出现时自动静音，“跳过”按钮可用时自动点击，回到视频正文后恢复原来的声音状态。

## 应用场景

你在 YouTube 播放讲座、访谈、新闻或其他长视频，同时做家务、运动、整理东西，或者睡前、睡觉时听视频。

人已经离开键盘，遇到广告还要特地回来点“跳过”。有些广告的声音明显高于视频正文，突然响起时容易打断休息，甚至把人吵醒。

这个扩展自动处理这些操作，减少手动点击和广告声音的打扰。

## 主要功能

自动跳过、广告静音和声音恢复集中在一个扩展中完成，开启后自动运行。主要功能如下：

| 功能 | 实际作用 |
|---|---|
| 自动跳过广告 | 自动点击开头和中途广告中已经可用的“跳过”按钮 |
| 支持后台播放 | 切换到其他标签页或窗口后，继续自动跳过广告并处理广告声音 |
| 广告期间静音 | 等待跳过时保持安静；不可跳过的广告静音等待自然结束 |
| 不改变播放器声音偏好 | 通过标签页临时静音处理广告，不修改播放器原有音量和静音偏好 |
| 保留原有静音状态 | 原本有声音，广告结束后恢复声音；原本已静音，结束后仍保持静音 |
| 尊重手动操作 | 广告期间手动调整声音时，保留你的选择 |
| 没有调试横幅 | 不使用 Chrome 调试接口，不会因本扩展操作出现“已开始调试此浏览器”提示 |
| 开启即用 | 使用 Chrome 扩展开关统一启停，无需逐个视频启动 |

例如：

- **原本有声音：**正文有声 → 广告静音 → 正文恢复声音。
- **原本已静音：**正文静音 → 广告静音 → 正文仍然静音。

## 怎么安装

无需编译，下载并解压后即可安装。

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，下载并解压。
2. 将解压后的文件夹放在准备长期保留的位置。
3. 在 Chrome 地址栏输入 `chrome://extensions/`。
4. 开启右上角的**开发者模式**。
5. 点击**加载未打包的扩展程序**。
6. 选择仓库中的 **extension** 文件夹，里面应直接包含 `manifest.json`。
7. 确认扩展已开启，刷新已经打开的 YouTube 视频页。

安装后请保留该文件夹，Chrome 会从这里加载扩展。

## 怎么使用

**启用扩展后，正常播放 YouTube 视频即可自动工作。**

点击扩展图标可以查看运行状态。需要停用时，在 Chrome 扩展管理页关闭开关即可。

## 适用范围

- 面向桌面版 Chrome，已在 macOS 的 Chrome 中完成实播和用户验收。
- 不处理创作者直接录进视频正文的赞助口播。

## 隐私与权限

扩展在本地运行，无需注册账号，也不需要额外安装其他程序。

| 项目 | 具体说明 |
|---|---|
| 网站访问范围 | 仅申请 `https://www.youtube.com/*`，用于识别广告状态、查找并点击“跳过”按钮 |
| 声音控制 | 使用 Chrome 的标签页静音功能，在广告期间临时静音，结束后撤销本扩展设置的静音 |
| 调试权限 | 不申请 `debugger` 权限，不通过浏览器调试接口操作页面 |
| 其他权限 | 不申请浏览历史、Cookie 或下载权限 |
| 数据传输 | 不向外部服务器上传视频信息、观看记录或页面内容，不接入分析统计服务 |
| 运行记录 | 弹窗显示当前页面的状态、点击次数和最近检测记录；这些数据保存在页面内存中，刷新后重新统计 |

扩展也会向浏览器控制台输出诊断信息，便于排查问题。以上说明针对本扩展自身，不涉及 YouTube 网站自身的数据处理。

## 参考项目

开发过程中参考了以下开源项目。下面按已核对的源码版本及公开问题记录列出不足。

| 参考项目 | 不足 |
|---|---|
| [yt-ad-autoskipper](https://github.com/squgeim/yt-ad-autoskipper) | 所核对的实现依赖固定的按钮样式，YouTube 改动按钮后存在需要重新适配的风险。[点击实现](https://github.com/squgeim/yt-ad-autoskipper/blob/cc4fc71cadbddf1f27f00cbd8b92f31115c9083d/src/contentScripts/youtube/overrideEvent.ts)。2026 年 3 月、8 月均有用户反馈“停止自动跳过”，截至 2026 年 10 月 26 日，相关问题仍未关闭。[问题 #85](https://github.com/squgeim/yt-ad-autoskipper/issues/85)、[问题 #87](https://github.com/squgeim/yt-ad-autoskipper/issues/87)。 |
| [AutoSkip](https://github.com/sakel4/AutoSkip/tree/fb628fb7d611654060455facf07caa62dcd9bd91) | 使用调试接口点击，Chrome 会出现顶部调试横幅；横幅很丑、突兀，影响观看体验。所核对版本也未提供广告静音功能。 |
| [ad-mute](https://github.com/1polygon/ad-mute) | 已整合自动跳过和广告静音，但广告结束后会直接解除播放器静音，没有保留用户原本的静音选择。原先静音播放的视频，也会被重新打开声音。[声音处理源码](https://github.com/1polygon/ad-mute/blob/fe81b534e664043732d615bbdda21109f331254c/youtube.js#L29-L40)。 |

在这些项目的思路基础上，**本项目的贡献**是将自动跳过、广告静音和声音恢复整合为开启即用的工具，同时补足声音状态保护，保留原有静音偏好和手动操作，并通过无需调试权限的点击方案省去顶部横幅，让离开键盘听视频的过程更安静、省心。基础功能已在 macOS Chrome 中完成实播测试和用户验收，后台处理另通过自动测试与真实 Chrome 后台模拟验证。
